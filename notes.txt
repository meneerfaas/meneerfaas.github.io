Environment gecreëerd in de folder env met mamba create -p ./env
(Empty environment created at prefix: env)
Environments info op te vragen met: mamba info --envs
Te activeren met: mamba activate ./env

Packages geïnstalleerd:
mamba install sphinx-design
mamba install pydata-sphinx-theme

Package list op te vragen met: mamba list
