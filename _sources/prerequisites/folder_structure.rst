Mappenstructuur
===================================

Wanneer je gaat programmeren, is een goede mappenstructuur onontbeerlijk. Ten eerste is het handig dat je zelf je codebestanden kunt terugvinden, maar bij grotere programmeerprojecten moet ook Python bestanden kunnen vinden.

Open in Windows een Verkenner met de toetscombinatie :kbd:`Win+E` (E van Explorer) of via het pictogram in de taakbalk.

.. figure:: images/explorer_01.png
    :class: image-border
    :alt: Windows Verkenner
    :align: center

Open je :file:`Documenten` map en maak daarin een map (bijvoorbeeld met :kbd:`Ctrl+Shift+N`) :file:`Python Projecten`. Eventueel kun je daarin nog submappen aanmaken voor bijvoorbeeld :file:`Oefeningen` of :file:`Experimenten`.
