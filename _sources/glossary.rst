Verklarende woordenlijst
===========================

.. glossary::
    :sorted:

    IDE
        **I**\ ntegrated **D**\ evelopment **E**\ nvironment. Een applicatie waarmee je code kunt schrijven en uitvoeren. In de lessen gebruiken we `Mu editor <https://codewith.mu/>`_. Een door gevorderde programmeurs veelgebruikte IDE is `Visual Studio Code <https://code.visualstudio.com/>`_.

    Shell
        Een omgeving waarin je rechtstreeks met Python kunt communiceren: je typt een regel code, drukt op :kbd:`Enter` en de regel wordt direct uitgevoerd. Je gebruikt de Shell vaak om even iets te testen; niet om programma's in te schrijven. Je herkent de shell aan de *prompt*: :tt:`>>>` |br|
        Andere benamingen voor de shell zijn *console*, *terminal* of *command line interface (CLI)*. Strikt genomen betekenen deze termen niet precies hetzelfde, maar veel programmeurs gebruiken ze door elkaar.
