Starter code#

Maak voor deze game een nieuwe map aan met de naam car driver. Start in Mu editor een nieuw codebestand en sla het op in de nieuwe map onder de naam car_driver.py.

Plaats de onderstaande code in het bestand.

car_driver.py#
 1# WINDOW SETTINGS
 2WIDTH = 600
 3HEIGHT = 400
 4TITLE = 'Car Driver'
 5
 6################################
 7# DRAW()
 8################################
 9def draw():
10    screen.fill('darkgreen')
11
12################################
13# UPDATE()
14################################
15def update():
16    pass

Deze code is min of meer de standaardwijze waarop je een Pygame Zero game begint. Je definieert de instellingen van het venster en zorgt voor een draw() functie en een update() functie. In dit geval vult de draw() functie het venster met een donkere groene kleur en doet de update() functie nog niets. Het keyword pass is een soort opvulling die je nodig hebt omdat Python geen lege functies toestaat.

De grote commentaarblokken in regels 6-8 en 12-14 zijn bedoeld om de code overzichtelijk te houden. Ze geven duidelijk aan waar de draw() functie begint en waar de update() functie begint. Dat is vooral handig als je later meer code aan deze functies toevoegt.

Kopiëren of zelf typen?

Uiteraard kun je de code in deze tutorials kopiëren en plakken in Mu editor, maar het is een beter idee om de code zelf te typen. Op die manier leer je de code goed kennen en begrijp je het beter.

Als je echt wilt leren programmeren, dan typ je zelf en stel je jezelf tijdens het typen bij elke coderegel de vraag: ‘Begrijp ik wat deze code doet?’ Dat is natuurlijk meer werk, maar het is de moeite waard.

In eerste instantie zullen we alleen de car_0 sprite gebruiken, maar voor de animatie van het rijdende autootje hebben we later alle vijf car sprites nodig. De emergency light sprites spelen pas een rol wanneer we de collision detection gaan implementeren.

Voor die animatie gaan we de pgzhelper module gebruiken, gemaakt door A Posteriori. Deze module biedt handige functies voor het werken met sprites en animaties in Pygame Zero. Download het bestand pgzhelper.py en plaats het in de hoofdmap van je project (dus in dezelfde map als je level_devil.py bestand).
